# 宿舍模型与渲染改进

2026-10-14。保持登录、指挥、学生、教师、复盘功能，重做实际三维模型和渲染。

建筑共21,477个构件，包含不透明门窗和墙体、墙裙踢脚、铝窗框、梁柱、消防箱、喷淋管、照明管、六人寝具、平台、双跑楼梯、斜扶手及屋面设备。主楼控制尺寸48×18m，楼梯塔和阳台外扩；尺寸为参考图下的米制假设。模型与IFC同源，IFC包含6层、186个室内空间，schema校验无错误。

GLB保留实体几何、基础材质、楼层和空间语义。网页在加载后应用本地扫描PBR贴图，因此独立打开GLB不会自动获得网页中的外部扫描纹理。材质来源及CC0记录见material-assets.md。实体剖切按构件section执行，没有把所有墙变成透明，也没有用参考效果图覆盖3D建筑。

Three.js采用HDR环境光和反射、2048阴影、GTAO环境遮蔽及4倍采样抗锯齿。第一人称使用实际走廊灯光，轨道控制器在学生模式停用，左右转向不会被覆盖。校园道路、树木、路灯与周边建筑为独立参数场景。

navigation.js定义实际平台站点、两跑踏步中心线、入口绕行和地面出口路径。199条连边使用折线距离，其中每层楼梯约12.15m。多智能体位置、学生下行及地面箭头共用折线；动画不再沿塔中心竖直移动。测试对所有路径按人体1.4m高度做射线检查，零实体阻挡。地面与寝室自由移动仍是简化行走区域，并非完整刚体碰撞引擎。

关门会转动源宿舍的门扇、门板、门把手和铰链，关闭的门阻挡学生进入，同时影响软件烟气交换。状态快照记录火源、门状态、实际路径和人员位置，支持回放。

火焰采用32步体积射线采样，烟气采用按房间/走廊字段驱动的噪声粒子，时间取演练秒，暂停及回放同步。它们是风险字段的图形表达，不是FDS求解结果。FDS/传感器契约继续保留，当前无需硬件。

人物从胶囊体改为带衣裤、双节四肢、头发、鞋、背包的实例网格。步态、弯腰和口鼻防护随运动与烟气变化；风险显示在脚下小环。远景降低几何细节，以控制绘制量。人物仍是简化角色，没有声称为照片级扫描人物。

验证：28项Node测试通过；生产构建成功，保留Three/ECharts分块体积提示；IFC4重新打开和schema校验成功。最终浏览器图像与差距记录在design-qa.md。此轮提高了实际3D的建筑与表面真实感，仍不标为原照片逐像素1:1或真实楼栋测绘模型。
