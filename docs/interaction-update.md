# 图层和学生交互更新

烟气、人员、路线按钮各自切换实际三维图层，再次点击可回到综合显示。烟气同时显示空间浓度色带、峰值、楼层和数据来源，演练未启动时明确显示无烟气。人员定位提供编号选择、状态颜色、跟随镜头与轨迹；选择人员时剖切到所在楼层，拖动画面停止跟踪。路线根据所选空间比较四个出口，展示包含楼梯的完整折线；封闭出口或风险变化会重算路径。

学生端默认第三人称，第一人称隐藏自身角色；地面引导可以关闭。相机和移动分别控制，斜向移动不会加速。自由探索覆盖走廊、房间、十字通道和楼梯平台，建筑源模型的墙体、家具、门框和门扇用于碰撞。关闭房门需要靠近门口，并避免夹住角色；其他房间也可交互。上下楼经过两跑楼梯和平台，有连续高度过渡。

开始前可以探索但不计分，暂停正式演练后停止移动。正式学生演练不会因虚拟人群先撤离完而提前终止，仍受600秒时限约束。火烟、风险、路线、动作与可视化均来自同一个 Twin State。

建筑采用参数化假设尺寸，火烟采用教学扩散模型。公开演示不代表现场消防验证，也不含实时传感器和服务器多人同步。
