# 校园火灾应急疏散 MVP

当前为独立定制的 Vue 3 + Three.js + ECharts 教学原型，未复制参考仓库代码。场景采用程序生成的教学楼第三层平面，包括 301/302/303 教室、走廊和两个出口。

## 启动

```sh
npm install
npm run dev
```

打开 Vite 输出的本地地址。生产构建：`npm run build`；核心测试：`npm test`。

## 操作

- 启动前点击教室选择火源，然后启动演练。
- 鼠标拖动旋转、滚轮缩放，切换俯视可观察节点路网。
- 封闭任一出口，观察人员重新选择路线；同时封闭双出口进入暂无安全路径状态。
- 暂停或继续时间推进；结束后查看规则评分与复盘提示。
- 导出 JSON 包含随机种子、人员状态、完整事件、趋势和评分。

## 模型

`src/simulation.js` 是不依赖浏览器的确定性仿真内核。统一的节点/边负责三维展示和路径计算。火烟按拓扑邻接扩散；风险综合火势、烟气、归一化温度与拥堵。寻路采用带风险边代价的 A*，欧氏距离作为下界启发值。危险通道和封闭出口直接禁行；无路可达返回 null。通道同时占用容量限制用于模拟排队。

当前评分是透明规则：完成率 40%、时间效率 20%、累积风险规避 25%、等待效率 15%。不是机器学习评分，也没有未采集的协同行为分。

## 当前范围与限制

这是单层、虚拟人员教学原型。尚未提供真实建筑 GLB、多楼层楼梯、WASD 用户角色、FastAPI/WebSocket、数据库、账户及批量预案优化。火烟不是 CFD 或经实测校准的物理模型。当前人员在边失效后回到上一节点重规划，后续需改为连续位置回退或最近安全节点策略。风险暴露按沿边位置插值积分，但没有独立烟气物理网格。仿真结束后需重置以开始新演练。

## 已完成验证

- 10 项 Node 单元测试通过：出口选择、出口封闭、烟气扩散、无路可达、风险绕行、暂停、出口恢复与重规划事件、未疏散评分、相对点火超时和确定性完整演练。
- Vite 生产构建通过。Three.js 与 ECharts 使主包较大，后续可做按需加载。
- 使用本机 Edge 无头浏览器通过 WebGL 场景、启动/暂停、双出口封闭、结束评分、JSON 导出、重置及移动端无横向溢出检查；无页面运行时异常。
- 浏览器自动检查脚本为 `tests/browser.mjs`，默认访问 `http://127.0.0.1:5174`。运行前先用 `npm run dev -- --port 5174 --strictPort` 启动服务，再执行 `npm run test:browser`。脚本使用 Windows 默认 Edge 路径。
